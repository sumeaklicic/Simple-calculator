# Simple-calculator

Four basic operations can be combined in this code. The program itself works by performing a new action on the last result, therefore there are brackets that should be used so that priority actions have priority.

Operations offered:

![image](https://github.com/user-attachments/assets/c76540fc-44f8-41b9-932d-de7b9d4466c4)


Given that this is not a program that can function like today's calculators, it is important to use the given possibility of using brackets. Otherwise, the program executes action after action regardless of the priority level of the operator.

This is the first calculator I made in C++ that performs operations in the most banal way
